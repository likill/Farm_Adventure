
# 🎮 **《Farm Adventure》——像素田园里的奇妙解谜之旅**

在《Farm Adventure》的世界中，一切看似宁静——阳光、农田、树林、还有那只调皮的小老鼠。  
你，将扮演一名热心的农场志愿者，开启一段充满**谜题与惊喜**的像素冒险。

---

## 🌾 **游戏特色**
- 🧩 **解谜与探索**：每一个场景、每一件物品都隐藏着线索。收集钥匙、金币和工具，解决农场的问题。  
- 🔨 **丰富的互动物品**：挥动你的镐子、锄头、斧头，甚至用蛛网去捕捉神秘的小动物。  
- ❤️ **动态生命系统**：心形代表着农民的幸福度，每一次的增长让每一次任务都充满乐趣与满足。  
- 💬 **剧情与对话系统**：通过对话与提示，拼凑出被遗忘的故事。  
- 🎨 **复古像素美术风格**：温馨而细腻的像素画面，让人仿佛回到 GameBoy 时代的纯粹感动。  
- 🎵 **沉浸式体验**：独特的 UI 字体与界面，让整个农场的气息更加真实。

---

## 👣 **你的目标**
探索农场的每一个角落，解锁隐藏的工具与道路，完成属于你的农场冒险故事。  
你能让所有的村民都幸福满满吗？
